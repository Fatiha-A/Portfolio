# Fethya's Portfolio Website

A responsive portfolio website showcasing my skills, projects, and contact information as a web developer.

## Features

- **Responsive Design**: Works on all device sizes
- **Multiple Themes**: Switch between 3 different color themes
- **Modern UI**: Clean and professional interface
- **Interactive Elements**: Smooth navigation and hover effects
- **Project Showcase**: Highlighting my best work

## Sections

1. **Hero Section**: Introduction with social links and call-to-action buttons
2. **About Me**: Background information and skills
3. **Projects**: Featured work with descriptions and links
4. **Contact**: Contact form and GitHub link

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## Theme Options

1. Default Theme (style.css)
2. Alternative Theme 1 (style-two.css)
3. Alternative Theme 2 (style-three.css)

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```
2. Open `index.html` in your browser
3. Explore the different themes using the theme buttons in the footer

## Customization

To customize this portfolio for your own use:

1. Replace the placeholder image in `assets/img/`
2. Update the personal information in the HTML file
3. Add your own projects to the projects section
4. Modify the CSS files to match your preferred styling

## Contact

For any inquiries, please reach out through the contact form on the website.
